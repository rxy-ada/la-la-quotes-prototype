# La La Quotes Prototype

这是一个演示原型，包含：

- 搜索栏（按情感关键词或自由文本搜索）
- 分类栏（按情绪/场景分类）
- 收藏（游客模式使用 localStorage；可通过输入微信号模拟查看好友收藏）
- 背景轻音乐（右上角喇叭切换）
- La La Land 风格的配色与排版

说明：
- 本站为原型演示，数据为示例/原创文本或公有领域风格的示例句子，避免直接展示版权受限的长摘录。
- 如果需要导入真实文本数据，请将 JSON 文件替换到 /data/quotes.json，格式参考示例。

部署：
- 当前仓库已创建。你可以使用 GitHub Pages 将此仓库部署为静态站点（Settings -> Pages -> Branch: main / root）。

微信打开：
- GitHub Pages 返回的 HTTPS 链接可以直接在微信内置浏览器打开；分享链接会以 query 参数的形式传递（例如：?share=id 或 ?favorites=wechatId）。
