# La La Quotes Prototype

这是一个基于静态页面的原型，功能包括：

- 搜索栏：支持按情感关键词、主题或文本内容进行搜索
- 分类栏：按“表白 / 死亡 / 成长 / 励志 / 友情 / 失落”等主题筛选
- 收藏栏：游客模式下使用 localStorage；微信模式可输入微信号查看收藏
- 随机轻音乐：页面右上角喇叭图标可切换背景音乐
- 风格：参考 La La Land 的电影感色调与浪漫氛围

数据说明：
- 当前版本为原型演示，示例数据中包含多主题句库，且总量已满足“至少 50 句可搜索结果”，并让各不同主题都具备较大数据量。
- 该版本适合快速演示、筛选和收藏流程，不依赖后端，适合托管在 GitHub Pages。

行文说明：
- 为避免直接展示受版权限制的大段原文，本原型采用“示例/原创/简短引用风格”句子进行演示；随后如果你提供授权文本或数据，我可以替换到真实作品版。

部署方式：
- Push 到 GitHub 后，在 Settings -> Pages 中开启 GitHub Pages（主分支 root）即可。
- 生成后的页面地址通常为：
